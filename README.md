## 🏗️ Featured Projects

### 🤖 1. PR Review Agent — Self-Hosted AI Code Review

A self-hosted AI-powered GitHub App that reviews pull requests by executing repository tests and linters inside isolated Docker sandboxes before using an LLM to analyze code changes.

**Highlights:**
- Secure, isolated code execution with Docker sandboxing.
- GitHub App integration and automated PR reviews.
- Asynchronous job processing with Redis and arq.
- Local and hosted LLM support through LiteLLM.
- Prompt-injection protection and execution cost limits.

**Tech:** Python · FastAPI · GitHub Apps · Redis · PostgreSQL · LiteLLM · Ollama · Docker

🔗 [Source Code](https://github.com/bhaviknagre/PR-REVIEW-AGENT-) | [Documentation](https://bhaviknagre.github.io/portfolio/)

### 📊 2. ChurnIQ — Agentic Customer Retention Platform

An intelligent customer churn prediction and retention platform combining machine learning with agentic workflows to recommend explainable, policy-checked customer retention actions.

**Highlights:**
- Customer churn prediction using XGBoost.
- Explainability using SHAP.
- LangGraph-powered retention agents.
- LLM-as-a-Judge for evaluating generated actions.
- Human approval workflows and audit logging.

**Tech:** Python · XGBoost · SHAP · LangGraph · PostgreSQL · Redis · Next.js · Prometheus

🔗 [Source Code](https://github.com/bhaviknagre/churnIQ)
